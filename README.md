# YY Rate List 📋

A fast, mobile-friendly **rate-list PWA** for a print shop — customers can browse printing rates online.

- 📱 Installable PWA with offline support (service worker)
- 🖨️ Built for PRINT POINT's real rate cards

Just open `index.html` in a browser, or deploy the folder to any static host.
